# Python Banking System
A simple banking system built using Python and Object-Oriented Programming (OOP) principles. This project demonstrates concepts such as inheritance, polymorphism, encapsulation, custom exceptions, and account management operations.

## Features
Create bank accounts, Deposit money, Withdraw money, Transfer funds between accounts, Custom exception handling for insufficient balance, Interest reward accounts with bonus deposits, Savings accounts with withdrawal fees, Balance inquiry functionality.

## Learning outcomes
This project was created to strengthen understanding of Classes and Objects, Inheritance, Method Overriding, Exception Handling, Code Reusability, Object-Oriented Design Principles.
